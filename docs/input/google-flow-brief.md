# Input: the Google Flow brief

This documents the Google Flow session that produced the six source clips. It is the *input* to this repo.

## Topic
Vector learning: how an AI understands concepts as directions in a space ("embeddings").

## How the concept evolved
1. **King − Man + Woman = Queen** — hook: "Tokens are just numbers." Loop: last line flows into the first. Easter egg: Token 9246 as a glowing dot hidden in the Queen vector.
2. **Simplified for a 4-year-old:** Kitty + Wings = Flying Kitty (Pip the Pixie-Bot, Toy Box Galaxy, Fluffy Hill). 2x2 storyboard generated.
3. **Aged up:** Horse + Wings = Pegasus, Horse + Horn = Unicorn, **Pegasus − Wings + Horn = Unicorn**. Six-panel (2x3) storyboard in a high-tech sci-fi fantasy style.
4. **Format fixed:** 48-second YouTube Short = six 8-second scenes, vertical 9:16, with lower-third captions.
5. **Clips generated** in Google Flow (video model "Omni 1.2 Flash", 144 credits for six) and a voice-over script written in ElevenLabs format.

## Scenes (8 s each)
| # | Scene | Visual | Lower third (burned into clip) |
|---|---|---|---|
| 1 | Hook & vector concept | Dark cosmic grid, golden numbers, neon vector lines | AI maps concepts as direction vectors. |
| 2 | Base vector node | Black futuristic horse at the origin of a 3D grid | Base Vector Node: Horse |
| 3 | Horse + Wings = Pegasus | Cyan WINGS vector; iridescent wings unfold | Horse + Wings = Pegasus |
| 4 | Horse + Horn = Unicorn | Magenta HORN vector; golden spiral horn grows | Horse + Horn = Unicorn |
| 5 | Pegasus − Wings + Horn = Unicorn | Wings dissolve to cyan particles while horn grows | Pegasus - Wings + Horn = Unicorn |
| 6 | Token 9246 & loop | Macro zoom into the horn; "9246" ignites; zoom out to the star-field | Token 9246 \| Seamless Loop |

## Voice-over (ElevenLabs, per scene)
1. How does an AI actually understand words? It doesn't read letters—it turns features into direction arrows on a giant map!
2. Think of this horse as a base vector. Every single concept sits at its own specific spot on the coordinate grid.
3. Add the "Wings" direction vector to the Horse... and the AI moves directly to the coordinate for Pegasus!
4. Add the "Horn" direction vector instead... and the coordinate shifts straight to Unicorn!
5. Which means... Pegasus, minus Wings, plus Horn, equals Unicorn! To an AI, concept logic is just basic geometry.
6. Token 9246 is hiding inside! But... how do these vectors talk to each other? How DOES an AI understand concepts?

Recommended ElevenLabs settings from the brief: Stability 35–45 %, Clarity/Similarity 75–85 %, Style 15–20 %, Speaker Boost on; voices Adam / Marcus / Charlie / Rachel.

## Why it loops
Scene 6 ends on the dark star-field with a lone glowing dot, the same as scene 1's first frame, and the closing question leads straight back into the opening line. Token 9246 is the Easter egg for people who watch twice.
