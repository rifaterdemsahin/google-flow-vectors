🧭 Input: how the idea evolved in Google Flow

  1. King − Man + Woman = Queen — hook “Tokens are just numbers”; the loop and the Token 9246 Easter egg were born here.
  2. Simplified for a 4-year-old — Kitty + Wings = Flying Kitty (Pip the Pixie-Bot, Toy Box Galaxy).
  3. Aged up — Horse + Wings = Pegasus, Horse + Horn = Unicorn, Pegasus − Wings + Horn = Unicorn.
  4. Format fixed — six 8-second vertical scenes with lower thirds = a 48 s YouTube Short.
  5. Clips + voice script — six clips generated; voice-over written in ElevenLabs format (Stability 35–45 %, Similarity 75–85 %, Style 15–20 %, Speaker Boost on).

Full written record: docs/input/google-flow-brief.md.

🛠️ How it was created

The whole video is code in this repo, so anyone can re-run it. Here is the path from idea to MP4:

  1. 🧠 Idea → storyboard (Google Flow). You started with “King − Man + Woman = Queen”, simplified it, and landed on Horse + Wings = Pegasus and Horse + Horn = Unicorn. Google Flow generated a six-panel storyboard, then six 8-second vertical clips with lower-third cards burned in. Those six MP4s are the input.
  2. 📥 Ingest. npm run ingest copies the six newest clips from Downloads into assets/clips/scene1…6.mp4 in story order.
  3. 🎙️ Voice-over (fal.ai → ElevenLabs). npm run tts sends each scene’s line to ElevenLabs through fal.ai (voice Adam, stability 0.4, similarity 0.8, style 0.15). Any line over 7.5 s is regenerated slightly faster so it never outruns its clip.
  4. ⏱️ Word timings (fal.ai Whisper). npm run align transcribes each voice file for word timestamps, then maps them onto your script’s own words, so “Pegasus” and “9246” are always spelled right.
  5. 🎞️ Compose (Remotion). A React project stacks six clips, the voice-over (clip audio ducked to 12 %), animated yellow word-highlight captions in the lower band above the burned-in cards, and a 2-second focused Skool end screen with a loop crossfade.
  6. 📤 Export + check. npm run build:video renders out/short_1080x1920.mp4; node scripts/verify-export.mjs confirms format, 49.5 s length, under 25 MB, and audible voice.
  7. 🚢 Ship. Trunk-based commits straight to main; GitHub Pages publishes this page, the clips and the final video.
